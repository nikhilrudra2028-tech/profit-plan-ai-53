# FarmProfit MLP

## Goal
Build a polished, mobile-first FarmProfit landing experience that takes farmers from uncertainty to a clear, comparable crop-profit estimate.

## What I’ll build
- Replace the placeholder home page with the complete FarmProfit landing page and shared navigation/footer.
- Create a strong first screen with the supplied messaging, Indian farming imagery, trust statement, and compact profit-plan preview.
- Add focused sections for the farmer problem, three-step process, four core features, scenario preview, pilot feedback, and final call to action.
- Build an accessible farm-plan form with validation for location, land size, soil, irrigation, budget, and previous crop.
- Add a short generation state, then reveal a polished mock results dashboard with the supplied Tomato recommendation, crop comparison, explanation, estimate labels, and disclaimer.
- Make every primary call to action bring the user directly to the planner.

## Visual direction
- Natural green, warm off-white, and restrained earthy accents.
- Premium agricultural SaaS styling with rounded cards, subtle depth, generous spacing, and clear typography.
- High-quality Indian farm imagery, with a simple interface suited to users with limited technical confidence.
- Responsive layouts for phones, tablets, and desktop, with restrained motion and reduced-motion support.

## Technical details
- Keep the experience frontend-only and use clearly labeled demo calculations; no live market-data claims.
- Separate reusable landing and planner pieces where useful, while keeping the product focused on the single farm-planning workflow.
- Define all colors, type, shadows, and motion as semantic design tokens in the global design system.
- Add complete page metadata and replace template branding.
- Validate the rendered experience at desktop and mobile sizes, including form submission and results states.
