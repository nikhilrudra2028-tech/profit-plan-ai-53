# Farm Plan Pro

Build a modern, premium, responsive web app called “FarmProfit” — an AI-powered crop profit planning platform for Indian farmers.

CORE VALUE PROPOSITION:
“Know your potential profit before you plant.”

The product helps farmers decide what crop to grow based on their land, location, soil, irrigation availability, and budget. The MLP should focus on helping a farmer move from “I don’t know what to plant” to “I can compare my options and make a confident decision.”

TARGET USERS:
- Small and medium-sized Indian farmers
- FPOs and agricultural consultants
- Agri-input retailers

DESIGN:
Create a clean, trustworthy, modern AgriTech design.
- Use a natural green + off-white color palette with subtle earthy accents.
- Premium SaaS-style UI, not an outdated agriculture website.
- Use high-quality visuals of Indian farms/farmers.
- Rounded cards, subtle shadows, clean typography, generous whitespace.
- Mobile-first and fully responsive.
- Make the interface extremely simple because many users may not be highly tech-savvy.
- Avoid excessive animations or clutter.

FUNCTIONAL REQUIREMENTS:
- Build the landing page and the basic farm-plan flow.
- CTA buttons should navigate to the farm input form.
- Form should validate inputs.
- Generate a realistic sample result after submission.
- Use mock/demo data for the MVP rather than pretending to have live agricultural market data.
- Make the architecture easy to extend later with real APIs and AI models.
- Include loading states while generating the farm plan.
- Make the dashboard visually impressive because this will be demonstrated as an AI-in-Business class project.

MOST IMPORTANT:
This is an MLP, so do NOT build a huge agriculture super-app. Keep the core experience focused on one job:

“Help me understand which crop could make the most sense financially for my farm before I plant.”

The website should feel like a real startup product that could eventually be launched, not a college-project template.
